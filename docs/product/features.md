# Три отметки — каталог фич

Название: **Три отметки** (otmetki). Название — наше, без символики Лесты.

Цель: один сайт, где есть всё, что сейчас разбросано по 15+ сервисам для «Мира танков» (Lesta, RU), плюс то, чего нет ни у кого.

Каталог собран по результатам исследования (сентябрь 2026): tomato.gg, kttc.ru, modxvm, wot-life, wotskill, tankist.net, lebwa.tv, protanki, poliroid, wotstat.info, tankistat.ru, tanks.gg, armor/map/replays.wotinspector, skill4ltu, mtreplays.ru, lesta-replays.ru, wotexpress, blitzstars, Belka, китайский клиент «坦克世界盒子» и др. Подробности — в [research/](../research/).

## Обозначения

- **[GAP]** — на RU-сервере этого нет ни у кого или сделано плохо. Главные козыри.
- **[UNIQ]** — нет нигде, наша идея.
- **Фаза** — P1…P5, см. раздел «Фазы» в спецификации.
- **Источник** данных:
  - `API` — Lesta API;
  - `DB` — наша накопленная история;
  - `MOD` — наш мод-компаньон;
  - `REPLAY` — разбор реплеев;
  - `FILES` — файлы клиента;
  - `SCRAPE` — сбор с сайтов;
  - `USER` — ввод пользователей.
- **Статус** (сверено с кодом на 2026-09-27), последний столбец таблиц и пометка *[статус]* в списках:
  - **есть** — работает в коде (сайт, бот или API);
  - **частично** — сделана часть, в скобках указано, какая;
  - **API** — есть на сервере, но нет веб-интерфейса;
  - **план** — не сделано.

Сводка сделанного — в разделе «[Сделано](#сделано-на-2026-09-29)» в конце файла.

## 15. Сообщество (P4)

- Поиск взвода: фильтры по скиллу, времени и голосу; статистика проверена. **[GAP]** *[есть: `/platoons`]*
- Биржа рекрутинга кланов с репутацией. **[GAP]** *[частично: `/recruiting` без репутации]*
- Каталог коучинга: бесплатная карточка тренера (статистика, контакты, ссылки на запись). **[UNIQ]** *[есть: `/coaching`]*
  - Ученик отправляет заявку с контактом и, по желанию, реплеем. Тренер принимает заявку и только после этого видит контакт ученика.
  - Об оплате ученик и тренер договариваются напрямую, вне сайта. Тренер отмечает занятие проведённым, ученик оставляет отзыв.
  - Дисклеймер в интерфейсе: «Оплата — напрямую тренеру, сайт не участвует в расчётах».
- Турниры сообщества: сетки, регистрация, проверка статистики. *[есть: `/tournaments`]*
- Гайды пользователей по танкам и картам, рейтинг авторов. *[есть: `/guides`]*

Намеренно не делаем: метки игроков «скриптер» и публичные «оленемеры» токсичности. Это травля и риск.

## 16. Мод-компаньон (P3)

- Python 2.7, пакет .wotmod, публикация через МОСТ и сайт. *[есть; страница мода — `/mod`: возможности, установка, честная игра, переключатели]*
- **Строго разрешённые категории**: сессия, отметки, итоги боя, свои выстрелы. Никакой информации о противнике сверх клиента.
- Функции:
  - шлёт итоги боя и события на наш сервер (пакетно, с подписью v2); *[есть]*
  - процент отметки в бою, «сколько урона не хватает»; *[есть]*
  - сессионная панель в ангаре; *[есть]*
  - автозагрузка реплеев; *[частично: сервер принимает загрузку от устройства мода, в самом моде её нет]*
  - привязка к аккаунту сайта одноразовым кодом; *[есть]*
  - применение настроек игры стримеров (выгрузка своих, применение чужих по запросу с сайта). *[есть]*
- Даёт данные, которых нет в API: точные проценты отметок (из них — пороги), экономика, карты, очередь, сборки.
