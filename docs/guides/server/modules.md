# Server modules

Part of the [style guide](../README.md). The server overview is [apps/web/server/CLAUDE.md](../../../apps/web/server/CLAUDE.md); this is the full reference of what each module owns.

A `*-worker.module.ts` next to a module is its half loaded by `WorkerModule` (processors and schedules); the rest is loaded by `AppModule`.

| Module                  | What it owns                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `achievements-rarity`   | Medal and tank rarity across the tracked population, collector points and the collectors leaderboard (`/achievements`, worker aggregate)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `accounts` | A user's linked Lesta accounts: `UserAccountsReaderService` (`accountIds`, `primaryAccountId`, `requirePrimaryAccountId`) and `USER_LESTA_ACCOUNT_ORDER` (primary first, then oldest link), the one place that picks a user's primary account |
| `analytics`             | Personal analytics under `/me/analytics`: overview, per-tank analytics, map advisor, platoon chemistry, honest-RNG view, battle list and battle review, evening playlist, first-win tracker, tilt                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `auth`                  | better-auth wiring, Lesta ID OpenID and Telegram sign-in, linked Lesta and Telegram accounts, account deletion (`deleteUser` → `AccountPurgeWriterService` purges the user's rows in one transaction)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `best-battles`          | Best-battles feed from mod battle reports with facets (tank, map, metric, period)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `billing`               | Три отметки Плюс: one plan (monthly/quarterly/yearly), trial, YooKassa checkout behind `PLUS.checkoutEnabled`, webhooks, promo codes, referrals, renewals/expiry (worker), entitlements + `@RequiresPlus`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `blog`                  | Editorial blog of the site team (`/blog/posts`, `/blog/tags`, RSS `/blog/rss.xml`, images `/blog/images/:file` on the `serverdata` volume under `.data/blog`); `/blog/editor/*` is guarded by `@Roles(BLOG.editorRoles)` (admin, moderator). | `bot-commands`          | Platform-agnostic bot core shared by Telegram, Discord and VK: stats/session/marks/clan/tank/top replies, linked-account lookup, Fluent store                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `builds`                | Loadout constructor under `/builds/:tank`: build options, loadout calculation, recommended and popular builds, the builds catalog                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `clan-workspace`        | Clan officers' workspace (web `/c/:tag/workspace` and Discord): events and reminders, attendance sync from mod battle reports, recruit funnel, weekly officer report                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |

| `coaching`              | Coach profiles with contact/booking links and booking requests; no payments                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |

| `community-builds`      | Shared player builds                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `community-core`        | Community accounts shared by the community modules; purges authored content on account deletion                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `community-maintenance` | Community worker: post expiry                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `compare`               | Player-vs-player and tank-vs-tank comparison                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `competitions`          | Community competitions (`/competitions/:slug`): create, join, leave, scoring in the worker                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |

| `events`                | In-game events calendar (`/events`, iCal feed `/events/calendar.ics`) and Twitch/VK drops                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |

| `lesta-links`           | Worker only: linked Lesta ID tokens — garage sync (`tanks/stats` with the token → `player_tank.in_garage`, 5 min after a login and daily) and daily `auth/prolongate`; a token that cannot be renewed marks the link stale and sends `lestaRelinkRequired`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `map-stats`             | Map rotation and queue-time aggregates from mod battle reports (`/map-stats/rotation`, `/map-stats/queue`)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `maps`                  | Maps from the arena data: detail, minimaps, team win rates                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `marks`                 | Marks of excellence tables, thresholds history, projections, sweat index, and `/v1/moe/:tankId` for the mod (always 200: `is_enough` plus the mod-data `curve` while the thresholds are unknown). The thresholds themselves come from the collector's `moe-estimate` job (source `otmetki`, from mod battle reports) or the flag-gated poliroid import — [docs/ops/moe-thresholds.md](../../../docs/ops/moe-thresholds.md)                                                                                                                                                                                                                                                                                                                                     |

| `mod`                   | Game mod ingest: device binding, signed (v2) event batches, event ledger (2 days; ledgered events older than that relative to `sent_at` count as duplicates), daily caps per account and Moscow day (`MOD_INGEST_QUOTA`: 5000 events, 300 new battles, then 429 `rate_limited` with Retry-After); every `/mod/*` error answers in the mod vocabulary except the site and manager routes in `MOD_REPLY.apiPaths`; the bound account's own ratings for the hangar (`/mod/me/overview`, `/mod/me/tanks` with records and WN8 expected values); `/mod/me/goals` lives in `me`, `/mod/me/replays` in `replays`, `/mod/me/sets` and `/mod/me/profiles` in `mod-sync`; `/mod/bind` takes the account from the request, else from the code, else the user's primary linked account                                                                                                                                                                                                                                                                                                                            |
| `mod-badges` | The modpack user badge ([spec](../../specs/2026-10-06-modpack-user-badge.md)): `POST /mod/badges` answers which of the asked arena account ids have an active bound device (seen in 30 days) that reported the badge on and no deletion request, storing no account id from the request (a device may ask about 1500 distinct accounts per Moscow day, counted over keyed hashes); `POST /mod/badges/preference` stores the device's switch (`mod_device.badge_visible`, deleted with the device). Both signed by the bound device, throttled per device |
| `mod-reports`           | Anonymous problem reports from the modpack manager (`POST /mod/reports`: versions, message, up to six log files): throttled per IP plus a Redis daily cap per hashed IP; only an HMAC of the IP is stored, and `RETENTION` drops a report after 30 days                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `mod-sync`              | Component sets and settings profiles synced between the modpack manager and the site (`POST`/`PUT /mod/me/sets`, `/mod/me/profiles`, signed by the bound device; `GET`/`DELETE /mod/sync` for the signed-in user): last-writer-wins per id with tombstones and a revision per library (`lib/library-merge`), in `/me/export` and purged with the account                                                                                                                                                                                                                                                                                                                                                                                                       |
| `moderation`            | Content reports and their resolution                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `modes`                 | Game modes (ranked, Onslaught, Frontline…): mode meta tanks and own per-mode stats                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |

Server-side copy is Fluent .ftl through @grammyjs/i18n: the bot, notifications (notifications/config/locales) and streamer chat (streamers/chat/config/locales) each load their files with createFluentStore from telegram/lib. Outside grammy they call i18n.t(locale, key, vars). Only the event → message-id mapping stays in TS.
