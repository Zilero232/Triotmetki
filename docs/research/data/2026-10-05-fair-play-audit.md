# Modpack fair-play audit (2026-10-05)

Every component of `apps/game/modpack/catalog/catalog.json`, plus the core and companion code that writes client settings or sends data, checked against Lesta's rules for client mods and our own fair-play rule (root CLAUDE.md «Fair play», `.claude/rules/modpack/fair-play.md`, `apps/game/modpack/CLAUDE.md`). The trigger: aim_info's armour readout under the reticle broke the support article's «анализ брони в бою» line. It is being removed in a separate change and is listed here only for completeness.

Method: the code of each component (its `client/` glue and pure `model/`), not only its catalog note, read on 2026-10-05; the rule texts fetched the same day.

## The rules

### Lesta support article 15152, «Запрещённые модификации клиента игры» [1]

Fetched 2026-10-05. Penalties: 7 days, then 30 days, then a permanent ban. The ten categories, quoted:

| #   | Rule (quoted)                                                                                                                                                                                                                                                                                                                         |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | «Моды, которые отображают позиции противника иначе, чем это реализовано в игровом клиенте: отмечая разрушенные объекты на игровом поле или мини-карте; изменяя способ отображения трассеров снарядов САУ или рассчитывая и отображая позицию САУ противника по её трассерам; показывая засвеченные машины противника, даже если игрок в них не целится и не направляет прицел.» |
| 2   | «Моды, которые показывают точку, в которую целится противник… Либо те, которые проецируют вероятную траекторию полёта снаряда на игровое поле»                                                                                                                                                                                        |
| 3   | «Модификации, которые сообщают о перезарядке машин противника или показывают их таймеры перезарядки.»                                                                                                                                                                                                                                 |
| 4   | «„Умные“ прицелы, которые предлагают больше возможностей, чем стандартный прицел, реализованный в клиенте. Особенно те, которые автоматически наводятся на слабобронированные или уязвимые места машины противника, либо фиксируют прицел на цели за препятствием, либо рассчитывают упреждение вместо игрока.»                         |
| 5   | «Модификации, которые меняют прозрачность объектов на карте.»                                                                                                                                                                                                                                                                         |
| 6   | «Моды, которые отображают какие-либо метки или индикаторы на игровом поле в том месте, где противник был замечен кем-либо из команды игрока.»                                                                                                                                                                                          |
| 7   | «Любые возможные модификации, которые меняют параметры техники или игровых объектов, влияющие на геймплей…»                                                                                                                                                                                                                           |
| 8   | «Модификации, которые отображают направление орудий каким-либо образом (например, в виде линии или сектора) на мини-карте.»                                                                                                                                                                                                           |
| 9   | «Модификации, которые указывают каким-либо образом направление на ближайших противников, находящихся вне поля зрения игрока.»                                                                                                                                                                                                          |
| 10  | «Модификации, которые указывают… местоположение противника на игровом поле за границей отрисовки.»                                                                                                                                                                                                                                    |
| A   | «Последняя категория — модификации для анализа брони в бою. Мы считаем, что этот функционал предоставляет игрокам значительное преимущество… мы пока не добавляем их в список… После создания этого инструмента аналогичные модификации с дополнительными функциями (к примеру, такими, которые отображают уязвимости в бою) будут внесены в список запрещённых.» |
| H   | «Мы абсолютно не против модов, действующих только в Ангаре (не во время сражения)… в список запрещённых попадают только те модификации, которые предоставляют дополнительную информацию в бою.»                                                                                                                                         |

The tanki.su guide [2] words item 4 as «больше возможностей, чем стандартный функционал захвата цели» and covers the same categories.

### Game Rules, 2.1.7 [3]

«Использование программ, имитирующих действия Пользователей в Игре (боты), программ-кликеров, макросов управления клавиатурой и мышью, иных подобных методов накапливания внутриигровых достижений, а также иные формы неспортивного поведения по усмотрению Администрации.» Item 1.19 also forbids using «запрещённые моды к Игре».

### МОСТ

Inclusion criterion: «мод не нарушает правила игры…» (curators' topic, [docs/ops/most-publishing.md](../../ops/most-publishing.md) sources [2], [8]). Its forbidden list is the same ten categories.

### Our own rule (stricter)

Only what the client already shows the player; client settings only through the game's own options, written on the player's change; hangar requests only on the player's request; nothing from other players sent to our server; grey features kept off by default.

## What changed

- No new clear violation beyond the armour readout, so no code or settings key was retired.
- `catalog/catalog.json`: the fair-play notes of `auto_reserves` and `hangar_tweaks` name their grey parts and why they are off.
- `apps/game/modpack/README.md`: a «Grey components» line in «Fair play», the 2.1.7 citation under auto_reserves.
- [docs/ops/most-publishing.md](../../ops/most-publishing.md) (archived 2026-10-05): the forbidden list quoted in full (item 1's three cases, item 4's examples, the armour-analysis announcement, the hangar exception), Game Rules 2.1.7 as source [11], `responsive_reticle`, `gun_arc`, `bush_circle` in the reviewer list, and letter items 7–9 (aim circle, auto reserves, exact scale with carousel rows).

## For the user

1. **ClientDefaults on a fresh install.** With `minimap_tweaks`, `camera_tweaks` and `crosshair_presets` on by default, the first hangar writes the recommended game options (minimap circles, names on Alt, «remember» sniper zoom, no dynamic camera, horizontal stabilisation) with a backup. Lesta allows it (game options only); `apps/game/modpack/CLAUDE.md` says «write only on the player's change». Resolved: these sections now start at «Как в игре» on every install and the recommended values are written only on the card's button (core 0.8.0).
2. **responsive_reticle stays on.** No rule text matches it, Lebwa ships it, and it shows nothing new; it is the component a strict reviewer may question. Turn it off by default if you want zero exposure.
3. **Grey and kept off by default:** auto_reserves, hangar_tweaks' exact scale and 3–5 rows, replay_upload (our rule only).
