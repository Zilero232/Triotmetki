# Настоящие превью компонентов

Превью в менеджере должны показывать игру, а не нарисованную карточку. Ниже — что уже настоящее, что нужно снять и как.

## Как снять

1. Поставьте dev-сборку: `cd apps/game/modpack && bun run dev:install` (без менеджерской установки в этом клиенте), затем `python tools/build/previews/capture --prepare` — он запишет в клиент `mods/configs/otmetki/capture.json` со списком id из таблиц ниже.
2. Запустите игру. В dev-сборке работают клавиши (в релизе их нет):
   - **Ctrl+Shift+F11** — следующий компонент; в ангаре придёт уведомление «следующий снимок превью — <id>»;
   - **Ctrl+Shift+F12** — снимок экрана средствами клиента в `<клиент>/screenshots/otmetki_<id>_NNN.png`; путь пишется в `python.log` (`bun run dev:log`) и в сообщении игры.
3. Для каждого id выставьте в окне мода настройку из таблицы, откройте нужный экран и сделайте снимок. Можно снимать один id несколько раз — берётся последний.
4. `python tools/build/previews/capture --list` покажет, что снято; `python tools/build/previews/capture` обрежет снимки по рамкам из [capture.json](capture.json), сожмёт до 640×360 и переключит `catalog.json` на `<id>.png` (старый SVG удаляется). Рамки — первая прикидка для 1920×1080 и масштаба интерфейса 100 %: если в кадр попало не то, поправьте `box` и запустите снова (`--dry-run` ничего не пишет).
5. `bun run test:modpack` и коммит `catalog/`.

Правила кадра: интерфейс игры по умолчанию, свой ник и цифры — можно, чужие ники в чате и ушах — замажьте или снимайте во взводе/тренировке; никаких данных, которые игра не показывает (fair play).
